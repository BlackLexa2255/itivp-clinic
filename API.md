# API

Базовый адрес: http://localhost:3000
Защищённые запросы требуют заголовок: Authorization: Bearer <токен>

## POST /auth/register

Тело:

```
{ "email": "patient@clinic.by", "password": "Patient#2026" }
```

Пароль: минимум 8 символов, хотя бы одна цифра и один спецсимвол.
Ответы: 201 — создан, 400 — не прошла валидация, 409 — email занят.

## POST /auth/login

Тело такое же. Возвращает токен и данные пользователя.
Ответы: 200, 400, 401 — неверный email или пароль, 423 — аккаунт заблокирован
после пяти неудачных попыток.

## GET /auth/me

Нужен токен. Возвращает id, email, роль и дату регистрации.
Ответы: 200, 401.

## Записи на приём

GET /api/appointments — список, доступен всем. Параметры строки запроса:
?status=scheduled — фильтр по статусу,
?doctor=козлов — поиск по части фамилии врача (без учёта регистра),
?date=2026-10-20 — фильтр по дате,
?sort=ticketCode — сортировка (ticketCode или date).

GET /api/appointments/stats — количество записей всего и по каждому статусу:

```
{ "total": 2, "byStatus": { "scheduled": 1, "completed": 1 } }
```
GET /api/appointments/:id — одна запись, доступна всем.
POST /api/appointments — создание, нужен токен.
PUT /api/appointments/:id — обновление. Обычный пользователь может менять только
свои записи, модератор и админ — любые.
DELETE /api/appointments/:id — удаление, только админ.

Тело для создания и обновления:

```
{
  "ticketCode": "T-2026-0010",
  "patientName": "Новиков Денис Олегович",
  "doctorName": "Козлов Игорь Львович",
  "date": "2026-10-20",
  "time": "12:00",
  "status": "scheduled",
  "diagnosis": "ОРВИ"
}
```

Обязательные поля: ticketCode, patientName, doctorName, date, time.
Номер талона уникален и должен иметь формат T-ГГГГ-НННН, например T-2026-0010.
Попытка создать запись с уже занятым номером возвращает 409.
Ответы: 200, 201, 204, 400, 401, 403, 404, 409.

## Пользователи

GET /api/users — список, доступен модератору и админу.
DELETE /api/users/:id — удаление, только админ.
Ответы: 200, 204, 401, 403, 404.

Все ошибки приходят в одном формате:

```
{ "error": "Недостаточно прав" }
```

У ошибок валидации есть ещё поле details со списком того, что не так.

## CORS

Браузерные запросы разрешены только с адресов из переменной CORS_ORIGINS.
Для запросов с другого адреса заголовок Access-Control-Allow-Origin не выдаётся.

## Ошибки

Коды: 400 — плохие данные, 401 — нет токена или он не подходит, 403 — не хватает
прав, 404 — не найдено, 409 — email занят, 413 — тело больше 10 КБ,
423 — аккаунт заблокирован, 429 — слишком много запросов, 500 — ошибка сервера.
