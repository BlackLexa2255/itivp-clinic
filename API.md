# Описание API

Базовый адрес: `http://localhost:3000`
Защищённые эндпоинты требуют заголовок `Authorization: Bearer <токен>`.

## Аутентификация

| Метод | Путь | Доступ | Назначение | Коды ответа |
|---|---|---|---|---|
| POST | `/auth/register` | все | регистрация пользователя | 201, 400, 409 |
| POST | `/auth/login` | все | вход, выдача JWT | 200, 400, 401, 423 |
| GET | `/auth/me` | авторизованные | данные текущего пользователя | 200, 401 |

Тело запроса регистрации и входа:

```json
{ "email": "patient@clinic.by", "password": "Patient#2026" }
```

Пароль должен содержать не менее восьми символов, хотя бы одну цифру и один спецсимвол.

## Записи на приём

| Метод | Путь | Доступ | Назначение | Коды ответа |
|---|---|---|---|---|
| GET | `/api/appointments` | все | список записей, фильтр `?status=` | 200, 400 |
| GET | `/api/appointments/:id` | все | одна запись | 200, 400, 404 |
| POST | `/api/appointments` | авторизованные | создание записи | 201, 400, 401 |
| PUT | `/api/appointments/:id` | автор записи, модератор, администратор | полное обновление | 200, 400, 401, 403, 404 |
| DELETE | `/api/appointments/:id` | администратор | удаление записи | 204, 401, 403, 404 |

Тело запроса создания и обновления:

```json
{
  "patientName": "Новиков Денис Олегович",
  "doctorName": "Козлов Игорь Львович",
  "date": "2026-10-20",
  "time": "12:00",
  "status": "scheduled",
  "diagnosis": "ОРВИ"
}
```

## Пользователи

| Метод | Путь | Доступ | Назначение | Коды ответа |
|---|---|---|---|---|
| GET | `/api/users` | модератор, администратор | список пользователей | 200, 401, 403 |
| DELETE | `/api/users/:id` | администратор | удаление пользователя | 204, 401, 403, 404 |

## Формат ошибок

```json
{ "error": "Недостаточно прав" }
```

Ошибки валидации дополнительно содержат поле `details` со списком нарушенных правил.

| Код | Когда возвращается |
|---|---|
| 400 | данные запроса не прошли валидацию |
| 401 | отсутствует или недействителен токен, неверный email или пароль |
| 403 | недостаточно прав для операции |
| 404 | элемент или маршрут не найден |
| 409 | пользователь с таким email уже существует |
| 413 | тело запроса больше 10 КБ |
| 423 | учётная запись временно заблокирована |
| 429 | превышено ограничение частоты запросов |
| 500 | внутренняя ошибка сервера |
