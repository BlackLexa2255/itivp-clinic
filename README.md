# Безопасное REST API сервиса записи на приём к врачу

Индивидуальная практическая работа 1. Node.js + Express.js + PostgreSQL (Sequelize),
аутентификация по JWT, ролевая модель, валидация и защита от типовых уязвимостей.

## Запуск

1. Установить зависимости:

```bash
npm install
```

2. Создать базу данных PostgreSQL:

```bash
createdb clinic_ipr21
```

3. Скопировать `.env.example` в `.env` и указать свои значения:

```bash
cp .env.example .env
```

| Переменная | Назначение |
|---|---|
| `PORT` | порт сервера |
| `NODE_ENV` | `development` или `production` |
| `DATABASE_URL` | строка подключения к PostgreSQL |
| `JWT_SECRET` | секретный ключ для подписи токенов |
| `JWT_EXPIRES_IN` | срок жизни токена |
| `MAX_FAILED_ATTEMPTS` | число неудачных входов до блокировки |
| `LOCK_TIME_MINUTES` | время блокировки учётной записи в минутах |

4. Заполнить базу тестовыми данными и запустить сервер:

```bash
npm run seed
npm run dev
```

Сервер доступен по адресу `http://localhost:3000`.

## Реализованные меры безопасности

Обязательные:

- хеширование паролей bcrypt, сравнение через `bcrypt.compare`;
- аутентификация по JWT, срок жизни токена 1 час;
- ролевая модель `user` / `moderator` / `admin`, middleware `roleGuard`;
- валидация всех входных данных схемами Joi, включая параметры маршрута и строки запроса;
- защита от SQL-инъекций: все запросы к базе выполняются через Sequelize с параметрами;
- заголовки безопасности через helmet;
- глобальное ограничение частоты запросов: 100 запросов за 15 минут с одного адреса;
- журнал подозрительных действий в `logs/security.log`.

Дополнительные (выбраны из таблицы задания):

| № | Мера | Реализация |
|---|---|---|
| 3 | Проверка сложности пароля | схема Joi: не короче 8 символов, цифра, спецсимвол |
| 6 | Ограничение попыток входа | 5 неудачных попыток – блокировка на 15 минут (`failedAttempts`, `lockUntil`) |
| 12 | Ограничение размера тела запроса | `express.json({ limit: '10kb' })` |
| 24 | Generic errors | подробности об ошибке только при `NODE_ENV=development` |

## Тестирование

Коллекция Postman: [postman/clinic-ipr21.postman_collection.json](postman/clinic-ipr21.postman_collection.json).
Импортировать в Postman, переменная `baseUrl` по умолчанию `http://localhost:3000`.
Запрос «Вход» сохраняет полученный токен в переменную `token`, остальные защищённые запросы используют её автоматически.
